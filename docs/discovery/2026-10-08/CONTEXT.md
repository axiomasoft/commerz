# Commerz — рабочий словарь исследования

Определения для сравнения вариантов модели. Словарь отражает текущую исследовательскую гипотезу; спорные границы отмечены в материалах исследования.

## Каталог

**Product / Товар**: описание предложения как семейства, например модель футболки. Не обозначает конкретный физический экземпляр.

**Variant / Вариант товара**: конкретная конфигурация товара, которую покупатель может выбрать, например футболка размера M красного цвета.

**SKU / Артикул**: бизнес-код учётной позиции в определённом пространстве кодов. Не тождественен самому товару, варианту или физическому экземпляру.

**Inventory item / Учётная номенклатура**: то, количество чего учитывают при хранении, резервировании и перемещении. Разные коммерческие предложения могут расходовать одну номенклатуру.

**Attribute definition / Определение свойства**: описание смысла, типа, допустимых значений и области применения свойства.

**Attribute value / Значение свойства**: конкретное значение определения свойства у товара, варианта или другого допустимого владельца.

**Variant axis / Ось вариантов**: характеристика, комбинации которой различают варианты одного товара. Например, размер и цвет.

**Customization / Персонализация**: выбор покупателя для конкретной покупки, например текст гравировки; сам по себе не создаёт новую складскую номенклатуру.

**Product family / Семейство свойств**: набор свойств, применимых к определённому классу товаров, например обуви или бытовой технике.

**Bundle / Комплект**: предложение из нескольких составляющих. Комплект, собранный заранее, и набор, комплектуемый при отгрузке, имеют разный складской смысл.

## Организация торговли

**Tenant / Контур владельца данных**: область ответственности и изоляции данных одного клиента системы. Не обязательно совпадает с юридическим лицом.

**Store / Магазин**: организованная точка торгового бизнеса. Может иметь несколько способов продажи и использовать несколько складов.

**Sales channel / Канал продаж**: способ и контекст продажи, например сайт, касса или маркетплейс.

**Listing / Публикация предложения**: присутствие товара или варианта в конкретном канале со своими условиями видимости и доступности.

**Customer / Покупатель**: лицо или организация, выступающая стороной покупки. Учётная запись пользователя — отдельное понятие.

## Склад

**Location / Место хранения**: физическое или операционно выделенное место, где учитывается номенклатура.

**Warehouse / Склад**: объект хранения, который может включать несколько мест хранения.

**Bin / Ячейка**: адресуемая часть склада для размещения и отбора запасов.

**Stock pool / Пул доступности**: набор запасов, из которого разрешено выполнять продажи для выбранного контекста. Сам по себе не создаёт новые физические запасы.

**On hand / Физический остаток**: количество номенклатуры, фактически находящееся в учитываемом месте на выбранный момент.

**Available / Доступное количество**: количество, которое по принятой политике ещё можно обещать для новой продажи.

**Reservation / Резерв**: временное обязательство удержать количество для конкретной потребности.

**Allocation / Назначение источника**: решение, из какого места и при необходимости какой партии выполнить потребность.

**Stock movement / Движение запасов**: изменение учтённого количества с причиной и происхождением.

**Lot / Партия**: группа единиц номенклатуры с общим происхождением или условиями прослеживаемости, например сроком годности.

**Serial unit / Серийный экземпляр**: отдельная физическая единица с индивидуальным идентификатором.

## Продажа и расчёты

**Price / Цена**: денежное условие продажи единицы предложения в определённом контексте.

**Quote / Расчёт предложения**: рассчитанный набор позиций и сумм с условиями применимости и сроком действия.

**Cart / Корзина**: изменяемое намерение покупателя приобрести набор позиций.

**Order / Заказ**: зафиксированное обязательство обработать согласованный набор позиций и условий продажи.

**Promotion / Акция**: правило предоставления коммерческой выгоды при выполнении условий.

**Coupon / Купон**: код или другой предъявляемый инструмент, разрешающий применить акцию. Акция может действовать без купона.

**Coupon claim / Удержание права на купон**: временно удерживаемое право применить купон в конкретной покупке в пределах его лимитов.

**Redemption / Использование купона**: состоявшееся применение купона в конкретной покупке по принятой политике подтверждения.

**Adjustment / Корректировка суммы**: объяснимое изменение суммы позиции, доставки или заказа, например скидка.

**Payment / Оплата**: процесс получения денег по обязательству, включающий возможные попытки и операции провайдера.

**Fulfillment / Исполнение заказа**: подготовка и передача заказанных позиций покупателю или перевозчику.

**Return / Возврат товара**: обратное движение или рассмотрение возврата купленных позиций.

**Refund / Возврат денег**: операция возврата ранее полученной денежной суммы. Не означает автоматически пригодность товара к повторной продаже.
