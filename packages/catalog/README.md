# axiomasoft/commerz-catalog

Products, variants, options, attributes, categories and per-channel listings. Provides the `variant` sellable.

Part of [Commerz](https://github.com/axiomasoft/commerz), an embeddable commerce
engine for Laravel (PHP 8.4, Laravel 13, PostgreSQL ≥ 16).

## Installation

```bash
composer require axiomasoft/commerz-catalog
```

Config: `commerz-catalog.php` (`max_generated_variants`). Plugin `commerz.catalog`, kinds `attribute_type` and `product_kind`.
