# axiomasoft/commerz-promotions

Discounts, coupons and usage limits; implements `PromotionUsage` and the three promotion quote stages.

Part of [Commerz](https://github.com/axiomasoft/commerz), an embeddable commerce
engine for Laravel (PHP 8.4, Laravel 13, PostgreSQL ≥ 16).

## Installation

```bash
composer require axiomasoft/commerz-promotions
```

Config: `commerz-promotions.php`. Plugin `commerz.promotions`, kinds `promotion_condition`, `promotion_effect`, `promotion_activator`. Command `commerz:promotions:reconcile`.
