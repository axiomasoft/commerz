# axiomasoft/commerz-sales

Carts, checkout, orders, payments, fulfillment, returns and refunds.

Part of [Commerz](https://github.com/axiomasoft/commerz), an embeddable commerce
engine for Laravel (PHP 8.4, Laravel 13, PostgreSQL ≥ 16).

## Installation

```bash
composer require axiomasoft/commerz-sales
```

Config: `commerz-sales.php`. Plugin `commerz.sales`, kinds `payment_gateway` and `order_number_generator`. Command `commerz:sales:expire-orders`.
