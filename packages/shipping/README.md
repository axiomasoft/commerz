# axiomasoft/commerz-shipping

Delivery zones, methods and tariffs, delivery options and carrier bookings; implements `DeliveryOptions` and `ShipmentBooking`.

Part of [Commerz](https://github.com/axiomasoft/commerz), an embeddable commerce
engine for Laravel (PHP 8.4, Laravel 13, PostgreSQL ≥ 16).

## Installation

```bash
composer require axiomasoft/commerz-shipping
```

Config: `commerz-shipping.php`. Plugin `commerz.shipping`, kinds `delivery_rate` and `carrier`.
